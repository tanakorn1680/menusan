# ProMenu 0.7

ปุ่มวงกลมลอย + แผงเมนูแบบสัมผัส สำหรับ GTA SA Android 2.10 (arm64, AML) รอบ 0.5 เพิ่มภาษาไทย (ยังไม่เคยทดสอบในเกมจริง)

## แท็บตอนนี้
- **Player:** ตั้งระดับตำรวจ 0–6, เลือด, เกราะ, เงิน (ปุ่ม −/+ และพรีเซ็ต)
- **Vehicle:** เรียกรถ 88 คัน แยก 5 หมวด (พับ/ขยายได้)
- **Teleport:** วาร์ปไปจุดหมายที่ปักบนแผนที่, วาร์ปตามพิกัด X/Y, สถานที่ 10 แห่ง, จุดของฉัน 6 ช่อง (บันทึกไว้ข้ามการเปิดเกม), ตัวเลือกวาร์ปลงใต้น้ำ ทำงานเหมือนเมนู ARM เดิม (โหลดฉาก หาพื้น/ผิวน้ำ วาร์ป วางบนถนน)
- **Game:** ซิงก์เวลากับเครื่อง, ความเร็วเกม, ตั้งชั่วโมง/นาที/ความยาววัน, วันในสัปดาห์, อากาศ (แดดจ้า/มีเมฆ/ฝน/หมอก/พายุฝน/พายุทราย/อัตโนมัติ), กล้องมุมสูง + ซูม
- **Cheats:** สูตรของเกมครบ 100 ตัว ลำดับเดียวกับ ARM CheatMenu เดิม จัด 12 หมวด
  - แตะครั้งแรก = เปิด แตะอีกครั้ง = ปิด มีข้อความ "Cheat NAME Activated/Deactivated"
  - ปุ่มที่มีสถานะจริงมีป้าย ON/OFF (อ่านจาก `m_aCheatsActive` ของเกม) สูตรแบบทำครั้งเดียวจบไม่มีป้าย
  - หมวด Danger ต้องแตะสองครั้ง
- **Menu:** เลือกภาษา English / ไทย, Overlay (FPS, พิกัด, เวลาเล่น, ตำแหน่ง 5 จุด, สี, ไล่สี RGB, ไม่มีพื้นหลัง), ตั้งค่าปุ่มลอย และข้อมูลวินิจฉัย

## ภาษาไทย
- Menu → Language → ไทย แปลทั้งเมนู ชื่อสูตร 100 ตัว และหมวด ชื่อรถยังเป็นภาษาอังกฤษ
- ต้องมีฟอนต์ไทย ปลั๊กอินหาเองจากโฟลเดอร์ฟอนต์ของ Android (ไฟล์ชื่อมีคำว่า Thai) หรือใช้ไฟล์ของคุณที่ `Android/data/com.rockstargames.gtasa/files/ProMenu/font_th.ttf` ถ้าไม่เจอ ปุ่มไทยจะกดไม่ได้
- ImGui ไม่ประกอบสระ/วรรณยุกต์ซ้อนกัน บางคำอาจเห็นเครื่องหมายชิดหรือทับกันเล็กน้อย

## แก้ไขใน 0.7
ปุ่ม Show coordinates ใน 0.6 เรียกฟังก์ชันพิกัดของเกมผิดวิธีและอาจทำเกมเด้ง 0.7 อ่านตำแหน่งจากตัวละครตรง ๆ แทน

## ที่ยังไม่ได้ทำ (รอบถัดไป)
Scene (คัตซีน), Visual, Vehicle (เครื่องมือรถ), Weapon, Ped และ Player ส่วนที่เหลือ รวมถึงใน Game: ล็อกซูมกล้อง, หยุดเวลาภารกิจ, น้ำแข็งตัว, แรงโน้มถ่วง และ Overlay ชื่อสถานที่

## ติดตั้ง / คอมไพล์
เหมือนเดิม: อัปโหลดไฟล์ขึ้น repo → Actions build → ได้ `libProMenu64.so` วางใน `Android/data/com.rockstargames.gtasa/mods/`
ไฟล์ `jni/cheat_table.inc` เป็นของเวอร์ชันเก่า ลบทิ้งได้

## ไฟล์ข้อมูล
- `jni/cheats100.inc` รายชื่อสูตร 100 ตัว (ลำดับ = ดัชนีในตารางของเกม ห้ามสลับลำดับ)
- `jni/cheat_groups.inc` ชื่อหมวด
- `jni/cheats100_th.inc`, `jni/cheat_groups_th.inc` ชื่อสูตรและหมวดภาษาไทย (ลำดับต้องตรงกับไฟล์ภาษาอังกฤษ)
- `jni/vehicles.inc` รายการรถ
